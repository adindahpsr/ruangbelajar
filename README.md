# ruangbelajar

Website pembelajaran interaktif yang menghadirkan materi dan permainan edukatif dalam satu halaman.

## Fitur

- Landing page dengan bagian Home, Features, Games, How It Works, dan Team.
- Permainan edukatif yang dapat dibuka melalui tautan.
- Tampilan responsif untuk desktop dan perangkat mobile.

## Cara Menjalankan

1. Buka folder project di Visual Studio Code.
2. Buka file `index.html`.
3. Klik kanan pada file, lalu pilih **Open with Live Server**.

Jika tidak menggunakan Live Server, buka `index.html` langsung di browser.

- HTML
- CSS
- JavaScript
